# 카카오 배송지 수동 검증

먼저 README대로 카카오 JavaScript 키와 허용 도메인을 설정하고 Live Server로 실행하세요. 키 미설정 상태를 배송 가능으로 처리하지 않습니다. 이 문서는 실제 키로 수행할 수 있는 테스트 절차이며, 아래 주소의 카카오 응답을 이미 검증했다는 뜻은 아닙니다.

구독 화면 → 배송지 영역 → ‘카카오 API 설정 및 배송지역 테스트’를 펼치면 다음 주소를 자동 입력하고 실제 검색하는 버튼이 있습니다.

| 대상 | 입력 주소 | 행정구역 확인 후 기대 결과 |
| --- | --- | --- |
| 동구청 | 대구광역시 동구 아양로 207 | 배송 가능 |
| 중구청 | 대구광역시 중구 국채보상로139길 1 | 배송 가능 |
| 파동 행정복지센터 | 대구광역시 수성구 파동로22길 7 | H 응답이 수성구 파동이면 배송 불가 |
| 태전2동 행정복지센터 | 대구광역시 북구 칠곡중앙대로52길 32 | H 응답이 북구 태전2동이면 배송 불가 |

주소 근거: [동구청](https://dong.daegu.kr/), [대구 동부교육지원청 관공서 안내](https://www.dge.go.kr/dgdbe/cm/cntnts/cntntsView.do?cntntsId=5129&mi=10192), [수성구 발급기 안내](https://www.suseong.kr/?menu_id=00000304), [태전2동 공식 안내](https://www.buk.daegu.kr/dong/index.do?menu_id=00000409). 주소·기관 위치가 바뀌었거나 검색 결과가 불명확하면 현재 공식 주소로 재확인하세요.

1. 위 네 주소를 하나씩 검색하고 지도·마커와 행정동 이름·코드를 확인합니다. 브라우저 Network에서 주소 검색과 좌표→행정동 API 응답도 비교합니다.
2. 동구·중구 허용 주소를 검증한 후 주당 배송 횟수만큼 요일을 선택하면 신청할 수 있어야 합니다.
3. 파동 또는 제외 북구 동으로 검증되면 빨간 배송 불가 메시지와 비활성 버튼이 표시되어야 합니다.
4. 허용 주소 검증 후 주소를 한 글자라도 바꾸면 즉시 신청이 비활성화되어야 합니다. 새 주소 검색 완료 후에만 허용합니다.
5. 북구 관문동·태전1동·태전2동·구암동·읍내동·동천동·국우동의 정확한 건물 주소를 각각 검색합니다. 법정동 이름이 다르더라도 **행정동 H 응답**이 제외 동이면 불가해야 합니다.
6. 수성구의 파동 외 주소, 북구의 제외 동 외 주소는 올바른 H/B 코드가 확인되면 허용되어야 합니다. 대구 달서구·남구·서구, 다른 도시 동구 등은 불가해야 합니다.
7. 건물번호 없이 넓은 도로명만 넣거나 다중 결과가 나오는 주소를 검색합니다. 검색 결과를 하나로 확정하기 전에는 배송 가능으로 처리하지 않아야 합니다.
8. 개발자 도구에서 오프라인으로 전환하거나 카카오 요청을 차단한 뒤 재검색합니다. 오류·미검증으로 표시하고 신청을 차단해야 합니다.
9. 정상 구독 신청 → 새로고침 → 내역 조회 → 수정에 진입합니다. 저장했던 주소여도 다시 검증해야 합니다. 수정 저장과 삭제가 정상 작동하는지 확인합니다.

행정동 코드 숫자는 이 문서에 추측하여 기재하지 않았습니다. 화면과 실제 API 응답에서 확인한 코드를 기록하세요. 자동 테스트 `qa_check.py`의 숫자는 합성 테스트용이며 실제 지역 코드로 사용하면 안 됩니다.
