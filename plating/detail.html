외부 API 실시간 조회

아래는 USDA FoodData Central의 검색 결과입니다. 위 판매 상품의 영양정보와 별개이며, 동일한 제품의 분석값이 아닙니다. USDA SR Legacy 자료의 100g 기준이며, 위 상품 1팩 전체 기준과 차이가 있습니다.

입력한 키는 저장하지 않습니다. 브라우저에서 직접 API를 호출하므로 요청 URL에 인증키가 포함됩니다.

USDA API 키 발급 및 연결 안내
  1. USDA FoodData Central 키 발급 페이지에서 이름과 이메일 등을 입력해 신청합니다.
  2. 발급된 data.gov API 키를 위 USDA API 인증키 입력란에 붙여 넣습니다. 키는 저장하지 않습니다.
  3. 샐러드·오렌지주스·사과주스·샌드위치·도시락은 영문 검색어로 자동 변환합니다. 다른 식품은 영문명으로 검색하세요.

키 없이도 공식 DEMO_KEY로 실제 요청합니다. 체험 키는 IP당 시간당 30회·일일 50회로 제한됩니다. 직접 요청하는 정적 웹앱에서는 요청 URL의 키를 숨길 수 없습니다. 개인 키를 공개 코드에 저장하지 마세요.
