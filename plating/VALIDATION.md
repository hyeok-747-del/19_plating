# 검증 기록

Chrome headless 자동 기능 검사 통과:

- 과제용 배포 HTML 두 개 유지: 첫 페이지 localStorage CRUD, 두 번째 페이지 USDA fetch와 응답 UI
- 샐러드 12종·음료 8종, 명시적 4주 순환 기본 식단
- 날짜별 기본 유지·대체 선택, 체크 성분 제외 후보, 동일 상품 2팩
- 대체 가격·요약 반영, 옵션 재계산 시 선택 유지, 기본 조합 복원
- 대체 선택 저장 및 수정 화면 복원

- 홈·메뉴·구독·내역 화면 분리와 URL 기반 이동·복원
- 후기 4개, 무한 슬라이드용 비노출 복제, 정지 버튼 제거, 이름 가운데 마스킹
- 11월 30일 중 월·수·금에만 26메뉴, 비배송일 메뉴 없음, 윤년 2월 29일, 이전·다음 달
- 같은 날 두 개의 서로 다른 메뉴 편성 및 날짜별 다양성
- 캘린더와 구독 일정의 동일 메뉴 사용
- 주 3회·4주 12회 출고·24팩
- 요일 수 부족 시 신청 제한
- 알레르기 경고와 해당 메뉴 표시, 경고 상태에서도 구매·저장 허용
- localStorage 생성·수정·삭제 및 신청 후 내역 화면 이동
- JavaScript 실행 오류 없음
- USDA 형식의 고정 JSON으로 영양소 표시, 0값 보존, 단위 변환, 누락값 처리
- API 빈 결과·429 오류·잘못된 상품 ID에서도 화면 유지

카카오 배송 검증 자동검사는 **가짜 SDK와 명시적으로 만든 합성 행정코드**로 실행했습니다. 실제 카카오 응답과 지역 코드를 검증한 것이 아닙니다.

- 동구·중구·수성구·북구 허용 판정, 파동 및 북구 제외 동 7곳 불가 판정
- 대구 외 도시와 대구의 다른 구 불가
- 행정동·법정동 코드 불일치, 행정동 누락 시 오류
- 키 미설정, 주소 미검증·변경, 제외지역, API 오류 시 신청 차단
- 다중 검색 결과는 주소 선택 전 차단
- 이전 주소의 지연 응답이 새 주소를 승인하지 못하도록 무시
- 배송 가능 검증 이후에는 알레르기 경고가 있어도 구매 허용
- 구독 수정 시 재검증, 주소 변경 후 재검증·수정 저장·삭제 유지

설정된 카카오 JavaScript 키로 SDK를 실제 요청한 결과, `http://127.0.0.1:5500`과 `http://localhost:5500` 출처에서 HTTP 401 `domain mismatched` 응답을 확인했습니다. 해당 키의 JavaScript SDK 도메인 등록이 필요합니다. 실주소·지도 타일·실제 행정동 코드는 아직 미검증입니다. `DELIVERY_TESTS.md`에 설정 후 수행할 수동 테스트를 정리했습니다. 제품 코드에는 모의 배송 성공 처리나 추측한 행정코드가 없습니다. 주소 검색 전 초기 지도 표시와 미승인 상태 유지도 모의 SDK 검사로 확인합니다.

실제 USDA 연결: 공식 DEMO_KEY를 사용한 읽기 전용 검색 요청에서 **HTTP 200과 foods JSON 응답**을 확인했습니다. 이는 네트워크 요청 검사이며, 고정 응답을 사용한 브라우저 UI 검사와 구분합니다. 개인 키와 사용자의 브라우저 네트워크 환경은 별도 확인이 필요합니다.

스크린샷으로 홈과 모바일 메뉴 화면의 레이아웃을 확인했습니다. 캘린더는 모바일에서 내부 가로 스크롤을 사용합니다. 사진은 로컬 assets에 포함했습니다.

프로젝트 상위의 `qa_check.py`를 Python으로 실행하면 Chrome 기능 검사를 다시 실행합니다. 설치된 Chrome 경로를 사용하고, 임시 HTML은 실행 후 삭제합니다. 실제 배포용 HTML은 2개입니다.


## 행정동 불일치 오류 수정 및 실제 응답 확인

실제 카카오 주소 검색 응답은 시 이름을 `대구`, 좌표→행정동 응답은 `대구광역시`로 반환했습니다. 코드가 같은데도 시 이름을 그대로 비교해 거부하던 오류를 수정했습니다. 이 두 표기만 통일하고 H/B 코드 일치와 제외 동 검사는 유지합니다.

실제 API 응답을 수집한 4개 주소를 수정된 `assess()`에 입력한 회귀검사를 수행합니다.

| 주소 | 실제 행정동 | H 코드 | 기대 판정 |
| --- | --- | --- | --- |
| 동구 아양로 207 | 신암5동 | 2714054100 | 가능 |
| 중구 국채보상로139길 1 | 동인동 | 2711051700 | 가능 |
| 수성구 파동로22길 7 | 파동 | 2726063000 | 불가 |
| 북구 칠곡중앙대로52길 32 | 태전2동 | 2723073500 | 불가 |

기록 파일: `tests/kakao-public-addresses.json` (프로젝트 상위 tests 폴더). 공개 관공서 주소만 포함하며 API 키나 고객 개인정보는 없습니다. 위 SDK 도메인·서비스 권한 오류 기록은 이전 진단입니다. 현재는 실제 주소·행정동 조회 응답을 확인했습니다. 지도 타일의 사용자 브라우저 시각 검증과는 구분합니다.
