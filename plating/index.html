02

배송받을 정보

플레팅 배송지역 확인

더 많은 곳보다, 더 신선하게.

플레팅은 고객님께 가장 신선한 한 끼를 전해드리기 위해 배송지역을 한정하여 운영합니다.

대구 동구 · 중구 · 수성구 일부 · 북구 일부

수성구 파동과 북구 칠곡권역은 제외됩니다. 출고는 월·수·금에만 진행합니다.

주소 확인 후 검색한 위치가 지도에 표시됩니다.
배송 주소를 검색하고 배송 가능 여부를 확인해 주세요.

주소 검색 시 입력 주소와 좌표는 카카오 API로 전송됩니다. 이름·연락처와 구독 내역은 이 브라우저에만 저장됩니다.

카카오 API 설정 및 배송지역 테스트

등록할 현재 JavaScript SDK 도메인:

‘카카오 지도 설정이 필요합니다’ 안내는 JavaScript 키가 입력되지 않았다는 뜻입니다. 키는 delivery-config.js에서도 설정할 수 있습니다. 카카오 Developers → 내 애플리케이션 → 앱 생성 → 앱 설정 → 앱 → 플랫폼 키에서 JavaScript 키를 확인하세요. 해당 키의 JavaScript SDK 도메인에 현재 주소의 출처(예: http://127.0.0.1:5500)를 등록하고, 키를 위 입력란에 붙여 넣은 뒤 배송지 확인을 다시 누르세요. 파일 더블클릭 대신 Live Server로 실행해야 합니다.

공식 설정 안내 ↗

아래 주소는 테스트용 관공서·행정복지센터 주소입니다. 실제 API 응답으로 판별하며 미리 배송 가능으로 지정하지 않습니다.
